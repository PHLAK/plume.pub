FAQ

Questions, answered.

What do I need to run Plume?

Docker. If you can run a container, you can run Plume. A single command brings up your blog with search, themes and RSS included.

Why flat files instead of a database?

Files are the most durable format there is. They're greppable, versionable with git, and backing up can be as easy as copying a folder. No exports, no migrations, no lock-in.

How do I publish a post?

Write a Markdown file, drop it in your data/posts folder, run plume publish, done. Plume picks it up automatically. Front matter, tags and all.

Does Plume support search?

Yes. Full-text search is built in, so readers can find any post without wiring up an external service.

Is Plume really free?

Yes. Plume is MIT-licensed open source. Self-host it, modify it, ship it.
